Every send containing @Canvas performs a new Canvas API fetch. Canvas responses are not cached by the extension.

Security notes

The token is equivalent to account access within its Canvas permissions. Do not commit it to GitHub or paste it into chats. This extension is read-only by design and issues only GET requests to Canvas.

Fresh Canvas context is included in the ChatGPT prompt when you invoke @Canvas, because ChatGPT needs that data to answer your request. The Canvas token itself is never included.
